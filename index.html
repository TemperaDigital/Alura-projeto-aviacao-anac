IMERSÃO ENGENHARIA DE DADOS · SETEMBRO DE 2026

Entenda o caminho dos dados até a decisão.

Engenharia de Dados transforma dados brutos em informações organizadas, confiáveis e prontas para análise. Esse trabalho sustenta decisões melhores em empresas e serviços. A IA ajuda a explorar dados, escrever consultas e documentar fluxos, com resultados sempre verificados por pessoas. SOBRE ESTE ESPAÇO

Uma trilha para ir além da aula.

Este guia reúne os arquivos HTML de estudo complementar disponíveis neste repositório e propõe uma ordem de leitura. O projeto VoeBem Analytics usa dados da ANAC para exercitar ingestão, transformação, qualidade e análise.

O ponto de partida é a Imersão Engenharia de Dados com IA da Alura, realizada de 14 a 18 de setembro de 2026. A iniciativa e as aulas são da Alura; este site é um material independente de apoio ao estudo.
